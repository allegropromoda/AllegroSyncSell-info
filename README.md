# AllegroSyncSell

AllegroSyncSell to prywatna aplikacja służąca do zarządzania sprzedażą na platformie Allegro.

## Przeznaczenie

Aplikacja jest rozwijana na potrzeby własnego konta sprzedawcy.

## Funkcjonalności

- Importowanie produktów z hurtowni.
- Zarządzanie cenami i stanami magazynowymi.
- Przygotowywanie ofert sprzedaży na Allegro.
- Planowana synchronizacja zamówień i przesyłek.
- Integracja z Allegro REST API.

## Status projektu

Aplikacja jest obecnie w fazie rozwoju i testów.

## Kontakt

Kontakt z twórcą aplikacji poprzez GitHub Issues w tym repozytorium.

AllegroSyncSell jest niezależnym projektem i nie jest oficjalną aplikacją Allegro.
